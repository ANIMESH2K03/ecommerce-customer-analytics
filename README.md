# E-Commerce Customer Analytics

End-to-end customer analytics workflow on the **Online Retail** transaction dataset, covering exploratory sales analysis, spend regression, repeat-purchase classification, RFM customer clustering, and collaborative product recommendations.

## What's Inside
- **Exploratory & Sales Analysis:** Monthly spend trends and top-selling products
- **Predictive Modeling:** Next-month spend regression and repeat-purchase propensity classification
- **Customer Segmentation:** RFM-based clustering into customer value tiers
- **Recommendations:** Item-based / nearest-neighbor product suggestions

## Dataset
Uses the public **Online Retail** dataset (`InvoiceNo`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `UnitPrice`, `CustomerID`, `Country`). Place the dataset file locally before running the notebook.
